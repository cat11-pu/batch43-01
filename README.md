# GSB Bugfix Task
## 题面
天赋树重做以后，洗点相关的工单一天能收几十张，客服已经把模板话术贴给我了。玩家洗完点发现返还的点数比投进去少两点，因为树里有两个节点是任务赠送的，系统把它们也算进消耗；双方案切换以后，旧方案的被动还挂着，两个方案的属性直接叠在一起，伤害凭空高了半截；战斗里切方案没有冷却，有人来回切把大招刷新了，竞技场录像一看就穿帮；洗点费用按当前等级算，玩家先降级再洗，少付了一大截，等于白嫖一次重置；点减号能一路点到负数，保存还成功了，面板显示欠系统三点；两个方案共用同一套技能冷却，切过去技能居然是好的，玩家用这个打双爆发；装备提供的额外天赋点，脱下装备后效果还在，等于凭空多出两点；方案导入导出的字段是老版本的，导进来点数全变零，玩家在论坛贴了截图；同账号双开同时编辑一个方案，后保存的把前一个覆盖，另一边的改动全丢；重置后任务给的天赋书没有退回，背包里少了道具；赛季结束强制洗点，补偿邮件只发给当时在线的人，离线玩家集体投诉；预览面板显示的数值和保存后的实际数值对不上，差了两百点生命。talent_respec_binder.py 的 TalentRespecBinder 管点数、方案和费用。天赋点必须守恒，投入加剩余等于总获得，任何操作后都不能为负；同一时刻只能有一个方案生效，切换要原子替换并重置对应技能冷却；方案保存带修订号，冲突时拒绝覆盖而不是硬写；扣费和返还写在同一个事务里，失败一起回滚。这套东西下周要上正式服，我不想再看到负点数。

```bash
python -m pytest tests -q
```
