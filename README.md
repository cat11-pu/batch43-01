# GSB Bugfix Task
## 题面
未成年人时长管理上线两周，家长投诉比之前还多，法务已经转来三封律师函。累计时长跨零点没重置，第二天一上线就被踢，家长以为孩子半夜偷玩；两台设备同时在线各计各的，实际玩了两倍时间，平板和手机一起开就行；宵禁时段按设备本地时间判断，改时区就能绕过，出国留学的账号反而被误伤；家长解绑以后孩子时长没恢复，客服要手动改数据库，一次一条；游戏内挂机不计时，玩家用宏绕过去，半小时点一次鼠标就能一直挂着；补偿时长发放没有上限，客服点了三次给了三份，一个账号多出六小时；跨游戏共享时长接口超时，本游戏直接放行，孩子先玩别的游戏再回来；实名信息变更以后年龄判定没刷新，成年了还被按未成年算；时长提醒在还剩一分钟时弹了五次，每次都要点确认，反而浪费游戏时间；强制下线时副本进度丢失，玩家回来发现自己被传回主城，队伍已经打完；节假日规则没生效，仍按工作日算，寒假和平时一个样；游客账号不计时长，登录正式账号以后也不合并，换游客模式就能继续玩。playtime_curfew_watch.py 的 PlaytimeCurfewWatch 要管累计、宵禁和补偿。时长按账号累计，和设备数量无关，多端在线只记一份；宵禁和节假日规则以服务端配置和账号实名信息为准，客户端时间不参与判定；强制下线前必须保存进度并留可恢复入口；补偿时长按批次幂等，重复点击不叠加。法务那边周三要看整改报告，先把多端重复计时和时区绕过两条修掉，剩下的月底前补齐。
