# GSB Bugfix Task
## 题面
昵称系统最近连续出事，合服公告发出去以后，抢注的人比平时多了十倍，客服后台堆了上百张昵称被抢的工单。两个玩家同时改到同一个昵称，两个都提示成功，社交关系里出现两个同名角色；改名以后旧昵称没有释放，别人想用一直提示被占；账号删除了昵称还锁着，新号起不了那个名；改名卡扣了但改名失败，卡也没退；合服以后重名，登录随机进到别人的角色；昵称里的全角半角和空格没有归一，看起来一样却能同时存在；改名冷却按客户端时间算，改系统时间就能绕过；客服强制改名没有释放旧昵称，本人自己改不了；账号恢复时昵称已经被别人占了，恢复直接失败；昵称预约到期没有自动释放，一直锁死；改名以后历史战绩和好友备注对不上人；进程重启预约记录丢了，昵称永久占着。nickname_lease_book.py 的 NicknameLeaseBook 管 claim、rename、release、restore。同一个昵称并发认领只能成功一个，另一个返回 name_taken 且不扣改名卡；改名成功必须在原子提交里释放旧昵称并绑定新昵称；账号删除后昵称进入保留期，到期自动释放，重启后按持久化到期时间继续；合服重名按规则加后缀，不能出现两个都能登录的同名角色。test_nickname_lease_book.py 的十五条用例，换了两台机器跑，照样全挂。

## 运行方式
```bash
python -m pytest tests -q
```
