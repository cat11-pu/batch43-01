# GSB Bugfix Task
## 题面
角色换上长披风以后，过场动画里布料的问题全暴露了：披风下摆穿过马鞍，跑起来整片布陷进马的身体里；帧率掉到三十，布料迭代次数跟着变少，同一条披风在高端机和低端机上形状完全不一样；角色急停或者传送以后，布料还留在原地往前甩，过两秒才整片跟过来；布料锚点跟着骨骼走，骨骼缩放以后锚点漂移，披风整片被拉长；碰撞体是移动的平台，平台升上去布料还停在原来的高度，直接穿过去；布料在远处切到低模或者按档位裁顶点，切回来形状对不上，低档位的披风还短了一截；场景里有风的时候，风场方向按世界坐标算，角色转身以后披风往反方向飘；暂停菜单打开，布料还在按墙钟继续模拟，关掉菜单已经变形了；两个角色离得近，布料互相穿模，还会被对方的碰撞体弹飞；同一段过场每次播放布料形状都不一样，美术没法做验收；布料数据在序列化以后丢了约束参数，读档回来变成一块硬板；显存紧张时布料缓冲被回收，角色身上直接少一块。披风是商城卖的外观，玩家对穿模特别敏感，截图一发论坛就是事故。布料模拟必须用固定时间步，帧率变化不能改变迭代次数和最终形状；同一初始状态和同一段输入必须得到可复现的结果，过场每次播放要一致；布料与角色的碰撞必须在同一帧内解决，不能把穿透留到下一帧；切到低模再切回来必须保持形状连续，不能跳变。

## 运行方式
```bash
python -m pytest tests -q
```
