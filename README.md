# GSB Bugfix Task
## 题面
套装效果改成动态计算以后，数值组和测试组天天吵架，平衡补丁已经拖了一周。四件套触发了两遍，因为戒指被算成两只手，伤害统计里多出一截，团本输出排名全乱；换下一件以后套装属性没撤，面板还显示六件，实际只穿四件；背包里两件同名装备被当成同一件，件数虚高，玩家把仓库那件也算上了；幻化和变身状态下件数算错，明明穿着四件只触发两件，外观党先发现；PVP 场景里套装效果按规则要禁用，属性却还在生效，竞技场胜率歪得厉害，排行榜前百全是同一套；套装百分比和天赋百分比用加法叠，实际应该相乘，伤害高了百分之十几；角色升级后旧套装失效，装备栏图标没跟着变，玩家以为还能用；断线重连以后件数从本地缓存读，和身上装备对不上，面板来回跳；两套套装各三件，系统同时给了两个三件效果，等于白送两条属性；预览另一套装备时，身上的套装效果被提前摘掉，出副本才发现属性少了；装备被锁定或者挂到交易行以后还计入件数，脱装备都甩不掉；跨服战场里套装编号映射错，特效变成另一套的，火系技能打出冰霜弹道。set_bonus_aggregator.py 的 SetBonusAggregator 要统一算件数和属性。件数只能由当前已装备且未锁定的物品唯一计数；属性重算必须整批替换，换装后旧加成一点都不能残留；同一套装按件数阈值只触发最高一档，多套之间取各自满足的档位；预览面板走独立快照，绝不能影响实际战斗属性。明天要出平衡性补丁，属性面板必须和战斗结算用同一份结果。

## 运行方式
```bash
python -m pytest tests -q
```
