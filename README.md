# GSB Bugfix Task
## 题面
跨服副本开放第一周，组队邀请的失败率接近三成，跨服副本门口经常站着进不去的人。同一个邀请点两次，对方收到两个入队弹窗；邀请过期了还能接受，点进去队伍已经满了；被拉黑的人照样能收到邀请，换了设备也一样；跨服邀请在目标服显示未知玩家，接受按钮点不动；队长邀请期间解散队伍，接受的人进了一个幽灵队；两个队长互相邀请，系统直接成环，两个人都不在队里；掉线重连以后待处理邀请全丢，对方以为已经同意；队伍人数上限按分线算，跨线以后超员；同一账号两个角色都收到邀请，两个都进队；副本里收到邀请，点接受直接被拉出副本；拒绝邀请以后冷却没生效，同一个人继续被骚扰；服务重启邀请关系没了，接受报 unknown_invite。invite_pending_book.py 的 InvitePendingBook 负责 send、accept、decline、expire。同一个邀请 ID 只能被接受一次，重复接受返回 already_joined；接受时要原子校验队伍存在、人数和拉黑关系，任一不满足返回对应错误且不入队；跨服邀请按账号 ID 路由，不能按角色名；未处理邀请要有明确过期时间，重启后保留到过期，已接受的不再恢复。test_invite_pending_book.py 的十五个用例，跨服那几条报的错还不一样，但全都没过。

## 运行方式
```bash
python -m pytest tests -q
```
