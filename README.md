# GSB Bugfix Task
## 题面
集合石改版后，招募列表和实际队伍对不上，从赛季初开荒期开始，集合石的成功率就一直在掉。同一个队伍连点发布，列表里出现四五条一模一样的招募，队长自己都分不清哪条有效；两个队长同时接受同一个申请人，申请人两个队都进了，副本只能进一个，客服只能给其中一队补次数；申请过期以后还能被点接受，进队时报角色已在别的副本；队伍满员列表没有下架，后面的人一直申请失败；队长把职业需求从治疗改成输出，之前按治疗提交的申请还是照样通过；跨区招募的时间按各自本地时区显示，玩家按显示时间赶过去已经过期；队长掉线队伍自动解散，申请人卡在等待界面没有提示；副本 CD 已经用掉的玩家仍能申请，进本被踢出来；编辑招募备注把已经通过的成员名单清空了；列表刷新一次，置顶的队伍直接消失；同一个账号两个角色同时申请同一支队，两个都占位成功；服务重启后申请关系没了，队长点接受报未知申请，当晚的团本车全部散架。lfg_recruit_board.py 的 LfgRecruitBoard 里 create、apply、accept、expire 各算各的。希望接受申请时原子占名额，并发接受只能成功一个，另一个返回 roster_full；申请带版本，招募条件改过之后旧申请返回 stale_application；名额占用要在接受的一瞬间落库，不能等进本才写；队伍满员立即下架并且不能再申请；重启后未处理申请和已占名额要恢复到一致状态。test_lfg_recruit_board.py 这十五条用例，压测环境和线上复现机都试了，结果一样难看。

