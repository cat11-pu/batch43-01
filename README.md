# GSB Bugfix Task
## 题面
办公网换 802.1X 认证以后，接入侧的问题一个接一个，网络组已经住了两天机房。证书过期了也能认证通过，补丁拖了三个月没人发现，监控也没告警；EAP 分片重组后长度字段没校验，一个超长报文把认证进程打挂，整层楼断网，会议室视频会议全断；证书 CN 映射 VLAN 用字符串前缀匹配，张三的证书匹配到了张三丰的权限，实习生直接进了财务网段；重认证期间旧会话还在转发流量，踢下线要等半小时，离职员工的账号还连着；哑终端 MAB 回退没有白名单，随便填个 MAC 就能进，打印机网段成了后门；交换机重启后端口保持已授权状态，谁插都能上网，机房门禁形同虚设；同一 MAC 在两个端口认证，两个端口都放行，网管排查环路排查了一晚上；计费开始发了两次，停止只发一次，月底对账对不上，多算了八千块，财务不肯签字；认证失败次数没有锁定，可以无限爆破，日志里一分钟几百次；EAP-Success 在身份还没确认时就下发了，客户端直接进桌面；中间人换了根证书没有告警，证书链校验形同摆设；访客 VLAN 能直接访问服务器网段，访客连上就能扫内网，安全扫描一查一大片。eap_tls_access_control.py 的 EapTlsAccessControl 要负责证书校验、端口授权和计费会话。证书链、有效期、用途和 CN 与 SAN 映射全部通过才授权端口；端口授权和计费会话绑定，重认证必须先撤销旧会话；同一 MAC 只能有一个授权端口，新认证顶掉旧的；失败次数达到阈值就锁定并告警，不得静默放行。安全部周四来查等保，先把过期证书放行和端口残留授权两条堵上。

```bash
python -m pytest tests -q
```
