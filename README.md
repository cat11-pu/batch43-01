# GSB Bugfix Task
## 题面
开了时间抗锯齿以后，画面是干净了，拖影也跟着来了。快速转视角时，画面边缘拖出一圈残影，停下来要半秒才收干净；角色跑动时整个人后面挂着三四个半透明的自己；怪物刷新传送的一瞬间，屏幕上拉出一条长长的色带；过场切镜头后，上一镜的树影还叠在新镜头上；粒子火焰没有运动矢量，跳动时糊成一团；半透明水面完全不参与重投影，倒影一直拖；界面文字被一起抗锯齿，笔画边缘发虚；改分辨率以后历史缓冲没重建，整屏像蒙了层旧画面；运动矢量算在裁剪空间而不是屏幕空间，实际位移只有一半；抖动序列没加进投影矩阵，抗锯齿几乎没效果，只是变模糊；动态分辨率切换时历史采样坐标错位，画面抖一下；分屏两个相机共用一份历史，左右画面互相污染。taa_motion_reprojector.py 的 TaaMotionReprojector 要维护每帧的相机和对象历史：运动矢量统一在屏幕空间计算，包含抖动偏移；每个可动对象保存上一帧变换，蒙皮按骨骼矩阵重算；相机切镜头、对象传送、分辨率变化时显式失效历史；粒子和透明物体按策略选择裁剪或单独处理；界面层不进时间累积；动态分辨率按归一化坐标重投影；分屏和 VR 每个视图独立历史。两条硬线：任何一次投影矩阵或历史版本不匹配都必须整帧丢弃历史，不能拿错位的历史硬混；同一帧提交的相机和运动矢量必须来自同一个快照。仓库里那十五条用例今天跑还是全红。

## 运行方式
```bash
python -m pytest tests -q
```
