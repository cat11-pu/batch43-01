# GSB Bugfix Task
## 题面
我们这个服拍卖行日均两万笔成交，改成分离式竞价以后，客服那边每天都有新段子。玩家设了五百金的代理价，别人出一百二，系统直接按一百二成交，代理价像根本没填，玩家追着要补差价；两个人的代理上限一样，先出价的那个反而提示被超越，后出价的人拿走商品；最后十秒有人加价，倒计时没有顺延，商品啪一下结束，卖家在群里骂街；出价刚好等于保留价，系统还是判流拍，卖家白交上架费；同一件紫装被两个买家同时点一口价，两边金币都扣了，邮件只发了一份；撤拍以后保证金退两次，或者干脆不退，财务对账多出一笔；卖家开小号抬价，抬完撤拍，手续费按虚高成交价扣；跨服拍卖行看不到本服上架的东西，切回本服又多出一条重复记录，同一个商品占了两行；金币和绑定币混着出价，折算汇率用的是上周的，差价全由买家承担；结算邮件一封带商品一封空着，玩家以为被骗，工单转到我们这边；系统时间往回校准时，已经结束的场次重新变成进行中；商品在拍卖期间被卖家从仓库取走，成交时没货可发，钱却已经进了卖家口袋。auction_bid_proxy.py 的 AuctionBidProxy 要管上架、代理价、一口价、延时和结算。同一件商品任一时刻只能有一个最高有效出价，代理价相同按先出价者胜；保证金、成交款和违约金三本账在单场拍卖里加起来必须为零，退款按拍卖编号幂等；结束时间只能单调前进，系统时钟回拨不得复活已结束场次；成交、流拍和撤拍要和库存扣减、邮件发放放在同一个事务里，任何一步失败整单回滚。拍卖行这摊子我先盯一周，先把钱和货对上。

