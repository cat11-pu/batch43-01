# GSB Bugfix Task
## 题面
举报系统这个月被工作室玩坏了，审核后台积了三千多条待办。同一个人被十个人举报，生成十条独立工单，审核员重复处理到半夜；举报附带的聊天记录只存了最后一句，前面的辱骂全没了，判定只能靠猜；被举报人改名以后工单里找不到人，客服只能按旧名字搜，搜出来一串重名；误封申诉期间账号一直封着，申诉通过时长也没补，玩家直接去消费者协会投诉；举报冷却按设备算，换个账号继续刷，一台机器能举报两百次；语音举报只留了文字描述，音频没存，根本没法核实，涉黄涉暴的只能放过；处罚到期不自动解封，要人工点一下，半夜到期的玩家第二天还在封；跨服举报落在举报人所在服，被举报人那个服看不到，工单在两个服之间踢皮球；举报人撤回举报，工单卡在审核中谁也不管，状态机没有回退路径；同一局比赛的回放被后面的对局覆盖，证据没了，申诉只能维持原判；批量举报脚本把正常玩家送进黑名单，一晚上误伤两百人，客服电话被打爆；审核结论只有通过和驳回，没有理由，客服没法回复申诉，玩家觉得是机器人判的。report_abuse_tribunal.py 的 ReportAbuseTribunal 要管受理、合并、审核和处罚。同一被举报人同一行为窗口内的举报合并成一条，证据快照只增不改；处罚和解封按时长自动执行，申诉通过立即回滚并补足被误封的时长；举报、审核、处罚三段都要留下可追溯的操作人和时间；对局回放按对局编号独立存储，不能被新对局覆盖。这周先把误封和证据丢失两条止血。

## 运行方式
```bash
python -m pytest tests -q
```
