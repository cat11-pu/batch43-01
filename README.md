# GSB Bugfix Task
## 题面
新赛季竞技场改成实时榜单，开服十分钟运营就发现排名对不上，公会群里天天有人贴截图问自己为什么掉了两名：两个人积分一样，刷新一次前后名次互换，谁都不服；赢一场加的分和输一场扣的分不是一套公式，越打越高；结算任务跑了两遍，同一批人加了两次分；有人半夜刷分被后台封掉，榜单没有重算，前一百里还留着他的名字；跨服合并时两个服的玩家编号撞车，名次叠在一起；榜单快照每小时落一次盘，玩家看到的实时名次和发奖用的快照差了一名，正好卡在奖励档位边上；赛季结束那一刻还有对局在结算，分数记进了新赛季；衰减逻辑按自然日算，维护跨天时有人一天被扣两次；查询前一百走了缓存，缓存过期前新上榜的人查不到自己；并列名次按达成时间排，时间戳只精确到秒，同一秒的几个人顺序随机；分页按名次偏移取数，前面有人掉榜，第二页会重复出现同一个人；节点重启后内存里的待结算对局丢了，赢了的分没加上。这份榜单被官网、游戏内面板和发奖脚本同时读取，口径必须一致。同一玩家一个赛季只能有一条有效积分记录，重复结算返回 already_settled，分数不能叠加；并列名次必须有稳定且可复现的排序键，刷新不能互换；封禁或删除玩家后必须触发榜单重算，前一百里不能留下无效条目；发奖必须读落盘快照，快照生成后到达的结算归入下一个赛季。

## 运行方式
```bash
python -m pytest tests -q
```
