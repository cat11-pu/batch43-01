# GSB Bugfix Task
## 题面
跨服私聊加上离线留言以后，玩家开始收到一星期前的过期消息。离线留言没有过期时间，上线后一口气弹出几十条，上下文早就没了；断线重连同一条留言被投递两次，聊天框里出现重复内容；先发的消息后到，后发的先到，对话顺序完全反了；拉黑名单只在下发时检查了一次，解除拉黑后旧的骚扰消息又补投过来；发件人删号后留言还在队列里，点回复报对象不存在；队列满了直接丢最旧的，发送方却显示已送达；两个大区的角色编号相同，留言投给了另一个区的同名角色；系统公告和玩家留言挤在一个队列，公告被刷到很后面；收件人在别的分线在线，消息一边推送一边又进离线队列，两边都收到；敏感词规则更新后，队列里的旧消息没有重新过滤就下发；时间戳一边用本地时间一边用世界时，排序全乱；玩家删除会话，服务端队列里的消息还留着，下次登录又回来。whisper_offline_postbox.py 的 WhisperOfflinePostbox 要按会话维护先进先出的队列，每条消息带发送时刻、过期时刻和全局唯一编号；投递按编号幂等，客户端确认之后才删除；拉黑和过滤在入队和投递两处都执行；发件人删号时把留言标记为不可回复；队列有明确上限，满了向发送方返回失败而不是静默丢弃；跨服消息按角色全局编号寻址；系统消息走独立高优先级队列；重启后按落盘顺序恢复未投递消息。两条硬门禁：同一会话的消息顺序不能颠倒，同一条留言无论重连多少次只能被确认一次。tests/test_whisper_offline_postbox.py 的十五个用例现在全部报错。

## 运行方式
```bash
python -m pytest tests -q
```
