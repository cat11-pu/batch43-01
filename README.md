# GSB Bugfix Task
## 题面
公会联盟功能上线两周，几个大服的外交频道就炸了。过期三天的联盟邀请还能点接受，两个公会凭空结盟；两个联盟用了同一个标签，成员列表在界面上混成一锅；解除联盟以后共享频道还能进，离开的公会照样能看对面的战术讨论；盟主公会解散，联盟没有跟着解散，宣战状态还挂着，成员每天照常吃败仗；结盟双方在野外互相攻击，友军保护没生效，误伤记录堆成山；联盟成员上限被两个官员同时邀请突破，多进来五个人；一个公会同时接受了两个联盟的邀请，两边都能看到它的成员；联盟战里同一次击杀被两个公会各记一分；普通成员也能点宣战，半夜把全盟拖进战争；退出联盟后历史聊天记录仍然对新成员可见；合服之后两个联盟编号撞车，宣战目标指向了错误的公会；联盟仓库的贡献值在解散后没有退回。guild_alliance_pact.py 的 GuildAlliancePact 要维护联盟的建立、加入、退出、解散和宣战状态：一个公会任何时刻只能属于一个联盟，接受邀请时在事务里检查双方名额和现有归属；邀请带过期时间和版本；退出或踢出立即撤销频道和友军标记；盟主解散要级联结束战争并归档仓库；宣战权限按职位实时校验；击杀积分按事件编号去重；合服时重新分配联盟编号并重写引用。两条硬线：同一公会不能出现在两个联盟里，联盟解散后不能残留任何生效中的宣战或共享权限。guild_alliance_pact 这套检查写了十五条，跑完没有一个绿点。

## 运行方式
```bash
python -m pytest tests -q
```
