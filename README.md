# GSB Bugfix Task
## 题面
新赛季语音频道改成默认开启，问题一下全暴露了，游戏内语音的检测和闪避最近很不对劲，打团的时候队友一会儿听不见一会儿被音乐淹没。背景音乐被当成说话，麦克风一直亮着；说话第一个字被切掉，队友只听到后半句；说完尾音被截断，像被掐掉；两个人同时说话，后说的那个被静音；按键说话和自动检测同时开，状态来回打架；游戏音效一响，语音反而被压低，本末倒置；静音以后噪声门没关，底噪一直在；网络抖动时状态机卡在说话中，一直占麦；四十八 k 和十六 k 采样率混用，检测阈值全错；热插拔麦克风以后增益没重置，一开口就爆；多人频道里 A 静音把 B 也静音了；长时间不说话，第一次触发延迟特别明显。voice_activity_gate.py 的 VoiceActivityGate 负责 detect、gate、duck、recover。起播延迟不能超过二十毫秒，首字不能被截断，结束挂起时间可配置；同一用户同一时刻只能有一个检测状态，按键说话优先，切换不能产生双讲；闪避只作用于游戏和音乐总线，语音总线增益不能被压低；设备热插拔要重置增益和滤波状态，重启后按持久化设置恢复。test_voice_activity_gate.py 的十五条用例，双讲那条每次都挂，其余也差不多。

## 运行方式
```bash
python -m pytest tests -q
```
