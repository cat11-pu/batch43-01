# GSB Bugfix Task
## 题面
主线剧情上线后，主角表情崩坏的截图成了梗，角色表情系统最近被玩家截图挂了出来。几个表情一起播，权重加起来超过一，脸直接穿模；形变以后法线没跟着走，高光位置不对，看着像塑料；眨眼和说话同时触发，眼睛被嘴部形变带跑；权重从一回到零有残影，网格停在中间态；切到远景 LOD 表情全丢，NPC 面无表情；GPU 蒙皮和 CPU 形变结果对不上，镜头拉近角色会跳一下；形态目标数量超过常量缓冲上限，后面的全被截断，嘴角不动；热重载表情资源以后旧句柄还在用，脸撕裂；动画事件在形变之前触发，口型对不上；两个角色共用一份形变缓冲，表情互相污染；存档里的权重精度丢了，重载以后表情轻微变形；设备丢失恢复后形变缓冲没重建，全员面瘫。blendshape_mix_state.py 的 BlendshapeMixState 负责 set、mix、apply、reset。每组形态目标权重必须归一化后再混合，总和不能超过一，超了要抛 ValueError 而不是截断；同一帧里形变必须在蒙皮之前完成，动画事件读到的是最终权重；切 LOD 时形变权重按通道映射保留，不能归零；并发更新同一角色要按帧序号串行，旧帧不能覆盖新帧。test_blendshape_mix_state.py 那十五条用例，美术同学跟着看了一下午，一条绿的都没见着。

## 运行方式

```bash
python -m pytest tests -q
```
