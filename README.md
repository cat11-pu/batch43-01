# GSB Bugfix Task
## 题面
播放器换成自研呈现器以后，二十四帧的片子在大屏上抖得厉害。每帧解码完立刻提交，六十赫兹屏上节奏一会儿两帧一会儿三帧，横移镜头像在跳格；音频走独立时钟，播十分钟画面比声音快出两三百毫秒；掉一帧以后连续补三帧，看起来反而更卡；拖动进度条清了视频队列，音频还停在旧位置，口型对不上；显示器切到可变刷新率，呈现节奏没跟着改，偶尔一顿；暂停再恢复会先闪一帧旧画面；队列满的时候丢的是最新帧，画面直接倒退；呈现时间戳用的是系统时钟，息屏再亮就整体错位；画中画和主画面共用一套呈现状态，小窗一动主画面也抖；切 HDR 时交换链重建，黑屏半秒；迟到的帧照样提交，观众看到一帧旧内容；蓝牙耳机接上以后音频延迟变了，补偿没重算。video_frame_presenter.py 的 VideoFramePresenter 要以音频为主时钟：每帧带媒体时间戳，呈现时刻按刷新率和音频时钟一起算；队列按时间排序，满了丢最旧；丢帧后不追补，直接跳到下一个合适呈现点；seek 时视频队列和音频位置在同一个操作里重置；暂停冻结当前帧，恢复从冻结时刻继续；可变刷新率和 HDR 切换要重建呈现参数并保持时间轴连续；每个视频实例独立状态；设备延迟变化重新标定音频偏移。两条硬门禁：呈现时间必须单调递增，任何一次 seek 或设备重建后音画偏差不能超过一帧。仓库里十五条用例现在全是红的。

## 运行方式
```bash
python -m pytest tests -q
```
