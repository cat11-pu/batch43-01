# GSB Bugfix Task
## 题面
手机云盘服务升级加密策略后，用户反馈重启机器后老照片打不开，新写入的文件又有一部分读不出来。客服排查时发现同一张照片在网页端能看、在手机端打不开，用户根本不知道是密钥问题；安全团队还要求密钥驱逐后旧文件不能被静默转成明文。密钥管理进程启动后密钥被驱逐，文件节点直接读不了；策略版本一和二的内容派生方式混用；进程重启后密钥不在会话钥匙串；目录策略变更不作用于已有文件；密钥描述符冲突，两把密钥互相覆盖；硬件内联加密和软件回退路径混用；文件打开时移除密钥直接报输入输出错误；文件系统不支持加密却继续写明文；轮换后旧文件仍用旧密钥写；并发加解密钥，映射丢失；子目录继承策略不一致；设备休眠唤醒后密钥环被清空，后台同步线程还在按旧映射读文件。服务端有几十万用户，不能要求用户重装应用，升级必须能原地完成，客服还要求错误提示能区分密钥丢失和文件损坏。密钥移除时仍有打开的文件，必须等最后一个句柄关闭后再驱逐，之后新打开返回 ENOKEY；策略版本不兼容必须报 FSCRYPT_POLICY_INCOMPAT，不能按旧版本静默处理；轮换完成后新写入只能使用新密钥，旧文件在密钥驱逐前仍可读；文件系统不支持加密时必须失败关闭，不能落明文。现在只能靠重启应用碰运气，投诉很多。

## 运行方式
```bash
python -m pytest tests -q
```
