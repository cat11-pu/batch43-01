# GSB Bugfix Task
## 题面
新资料片加了阵营声望，上线一周客服就被声望问题淹了：交任务加了两次声望，同一个任务奖励领了两遍；声望到达崇敬以后还在往上涨，界面显示超过上限，商店却按封顶算；活动期间双倍声望和公会加成叠在一起，实际加了四倍；玩家转阵营以后，对立阵营的声望没有清零，两边都能买对方的东西；声望是角色级的，换小号以后大号进度显示成零；敌对状态没跟着声望走，声望已经仇恨了，守卫还在跟玩家打招呼；达到阈值解锁的商店，声望掉回去以后商品还在卖；每周衰减任务跑了两遍，有人一周掉了两级；跨服战场结算的声望记到了错误的阵营；玩家举报刷声望，后台把声望扣回去，已经买走的物品没有追回；界面缓存了上次的声望值，交完任务不刷新，切阵营分页时列表还错位，显示成另一个阵营的数据；维护重启后当天的声望获取记录丢了，客服查不到流水。声望挂在所有阵营商店和任务前置上，改错一次就是全服回档，运营不敢随便发版本。同一任务对同一角色只能结算一次声望，重复提交返回 already_granted，不能叠加；声望必须限制在阵营定义的上下限内，超过上限的部分丢弃并记录；转阵营必须原子清零对立阵营声望并刷新商店权限，不能出现两边通吃；声望流水要落盘，重启后能按角色和阵营查回每一笔变动。

## 运行方式
```bash
python -m pytest tests -q
```
