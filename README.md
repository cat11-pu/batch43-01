# GSB Bugfix Task
## 题面
泛光重做以后，画面组天天在群里发对比图，宣传片的档期已经往后推了。白天天空整片发白，阈值低得离谱，云层细节全被吃掉，美术说像蒙了一层纱；夜晚路灯周围出现方块状光晕，下采样根本没做滤波，像打了马赛克；高亮像素一移动就闪，萤火虫满屏，玩家说看久了眼睛疼；泛光链叠了五遍，越亮越糊，霓虹招牌糊成一团，字都认不出来；UI 也被泛光影响，血条边缘在发光，低血量时整个界面泛红，夜里打本看不清蓝量；相机曝光变化时泛光慢一帧，切场景像有人拉了一下亮度；分辨率换到 2K 以后光晕半径按像素算，小了一半，夜戏气氛全没了；泛光颜色偏绿，颜色空间用错了，白光变成青绿色；半透明粒子被泛光放大成一大团，烟雾弹变成发光球；关掉泛光画面整体变暗，曝光补偿偷偷依赖泛光结果，参数根本没法调，两组人来回改；多相机渲染时后处理的泛光互相叠加，分屏两边亮度不一样，右侧明显更亮；泛光链最后一层没清理，切关卡残留上一关的光斑，主菜单和加载界面也带着。bloom_chain_threshold.py 的 BloomChainThreshold 要负责阈值、降采样链和合成。阈值按曝光后的亮度计算，同一场景不同曝光下高光范围要一致；每级先滤波再降采样，上采样权重归一，不能出现网格块；泛光只作用于场景颜色层，UI 和调试层必须隔离；分辨率或者曝光变化时整链重建，禁止新旧缓冲混用。下周要拍宣传片，导演只给了三天，先把天空发白和方块光晕这两条修掉，剩下的排到下周。

```bash
python -m pytest tests -q
```
