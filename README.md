# GSB Bugfix Task
## 题面
社交系统改版以后，客服那边关于好友的工单一直没断：有人加了对方，自己列表里有，对方列表里没有，组队时提示不是好友；两个人同时点添加，各自生成一条待确认申请，都点了同意，好友列表里出现两条同名记录；拉黑一个人之后，对方还是能发组队邀请，邀请点进去还能进队；单方面删好友，对面列表里还留着，私聊也照发不误；合服以后同一对玩家变成两条关系，好友数直接翻倍，上限被撑爆；上限只按自己这边的记录算，实际能加两倍的人；申请放了三天已经失效，点同意照样成为好友；角色改名以后好友列表显示旧名字，点开会话报找不到角色；角色删除重建，旧关系自动挂到新角色身上；对方离线时发的申请，上线没有任何提示，过期了才看到；拉黑和好友同时存在，界面一会儿显示好友一会儿显示已拉黑；运维重启社交服，待确认的申请全没了。这套关系数据同时被组队、私聊、邮件和排行榜引用，改一处要跟着回归一圈。同一对玩家只能存在一条有效关系，重复申请返回 request_pending，不能生成第二条；拉黑优先于好友，拉黑生效时必须同时隐藏或解除好友关系，且对方不能再发邀请；好友上限按双向去重后的数量计算，合服合并不能重复计数；进程重启后待确认申请和已生效关系都要恢复，不能只恢复一半。

## 运行方式
```bash
python -m pytest tests -q
```
