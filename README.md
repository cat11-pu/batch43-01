# GSB Bugfix Task
## 题面
体力系统改版后，玩家整理出一堆刷体力的办法。离线恢复从登录那一刻倒推，下线三小时再上，体力直接满；只过了半分钟也加一整点，反复重登就能无限涨；两台设备同时消耗最后一点体力，两边都进了副本，体力变成负数；买体力超过上限的部分被吞了，钱照扣；升级提高上限以后，差额没补，反而白送一整管；夏令时切换那天，每日补充提前一小时，有人领了两次；扣体力开副本，副本创建失败，体力没退；维护期间恢复暂停，开服后按墙钟一次性补了十个小时；邮件送的体力超过上限，多出来的直接消失；客户端自己算体力，带着过期数值请求消耗，服务端照单全收；体力药在满体力时使用，药没了，体力没加；服务器在恢复结算中途重启，同一次恢复被算了两遍。stamina_regen_meter.py 的 StaminaRegenMeter 要把体力当成带时间戳的账本：每次变化记录当前值、上限和结算时刻，恢复量按单调时钟的完整区间计算并保留余数；消耗用条件更新，只有当前值足够才扣；退款按流水号幂等，已退过的不能再退；上限变化只补差额或按配置重置，不能白送；每日补充按服务器周期边界；重启后余数和下次恢复时刻必须接得上。两条硬门禁：体力任何时刻不能为负也不能超过上限，同一笔消耗或退款无论重试多少次只能生效一次。仓库里十五条用例今天跑还是全红。
