# GSB Bugfix Task
## 题面
任务链改成图结构以后，策划自己都说不清哪些能接，测试只好拿着表格一条条点。前置没做完，后续任务的 NPC 头上已经有感叹号，点了也能接，剧情直接跳到第三章；放弃任务后已收集的物品没回收，重新接又给一份，玩家刷任务物品卖钱；队伍共享击杀，离队的人也算进度，站在主城挂机也能完成；同一个任务能接两次，奖励领了两份，经验条直接涨了一级；跨版本任务编号变了，老玩家进度全部丢失，回归用户一上线发现主线回到第一章；任务需要的 NPC 被剧情写死了，任务卡在那里完不成，只能等客服手动跳；任务物品可以交易，别人帮忙交任务，代练靠这个接单；自动寻路走到一半目标点消失，角色原地转圈，玩家以为卡号；每日任务和主线共用计数器，主线进度被日常覆盖，做日常等于白做主线；任务完成以后奖励邮件延迟十分钟才到，玩家以为没发，又交了一遍；不同阵营的平行任务链互相解锁，联盟角色能接部落专属；断线重连后任务追踪栏清空，玩家以为任务没了，重新跑去接发现已经完成。quest_chain_prereq.py 的 QuestChainPrereq 要维护前置图、任务实例和奖励。接取前必须校验整条前置链的完成状态，不能只看直接前驱；任务物品按角色绑定并唯一计数，放弃或失败要原样回收；同一任务同一角色只能有一个进行中实例，重复接取返回已有那个；任务状态变更和奖励发放写在同一事务里，进程重启后能恢复。策划说明天要对全部任务链，今天先把跨阵营解锁和重复接取按住。
