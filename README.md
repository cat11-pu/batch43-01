# GSB Bugfix Task
## 题面
音频后端支持热插拔以后，玩家插拔耳机就开始出怪声。拔掉耳机，声音没有切回扬声器，游戏直接静音，日志里也没有报错；蓝牙耳机连上后采样率变成四十四点一，引擎还按四十八输出，整体音调低了一截；从立体声切到五点一，总线映射没重建，人声跑到低音炮；两个输出设备同时活跃，同一句台词播两遍；设备初始化失败时音频线程直接崩，整个游戏退出；系统默认设备在回调中途变化，缓冲区写到一半换了目标；同一副耳机反复插拔，每次多出一组重复的 voice；延迟补偿没更新，过场口型和声音差半拍；独占模式被后台切换抢走，恢复后没有声音；重采样器状态没清，切回原设备时第一声有咔哒；设备移除时还有缓冲在队列里，回调访问已释放对象；热插拔事件短时间连发，音频线程被拖到卡顿。audio_device_switchboard.py 的 AudioDeviceSwitchboard 要维护设备列表和当前输出：设备变化先在新设备上建好格式再原子切换，切换期间旧设备继续播完当前缓冲；采样率或声道数变化时重建总线和重采样器，并从当前播放位置续上；同一物理设备去重，重复插拔不能复制 voice；回调里不加锁、不分配内存，设备句柄用引用计数保护；初始化失败回退到空设备并保留恢复入口；延迟变化通知混音器重算补偿。两条硬门禁：切换过程中不能出现访问已释放设备的回调，任何格式迁移后已播放的样本位置不能倒退。tests/test_audio_device_switchboard.py 的十五项检查眼下全部挂红。

## 运行方式
```bash
python -m pytest tests -q
```
