# GSB Bugfix Task
## 题面
新版本加了湖泊和近海，玩家开船跑一圈就能看出水面是假的：深浅交界处颜色突然从浅绿跳到深蓝，中间没有过渡；浪高从高度图采样，船和浮标用的却是另一套解析波形，平时船底一半沉在水里，暴雨把浪高拉满时整条船直接沉下去；远处水面网格精度低，近处精度高，接缝处能看到一条锯齿；水面法线只按一张贴图滚，两块水域滚动方向相反，拼在一起像两块布；岸边泡沫按固定宽度画，陡岸上泡沫飘在半空；折射采样没有做深度裁剪，岸上的树被折射进水里；半透明水面和船帆的排序每帧在变，帆一会儿在水上一会儿在水下；风平浪静时高光还是一个劲地闪，太阳位置没变却在抖；拖网渔船开过以后尾迹一直不消失，内存越占越多；相机贴近水面时近平面裁掉整片水，从水下往上看又是透的，从岸上看同一片水却像镜子；切画质档位以后浪的振幅没跟着改，低画质反而更颠；设备丢失恢复后水面着色器编译失败，整个湖变成粉红色。这片水域是新手村到主城的必经路线，晚高峰玩家全挤在岸边。同一位置的水面高度只能有一个来源，物理采样和渲染必须一致，船不能半沉；相邻精度网格的接缝必须共享边缘顶点，任何视角都不能透光；水面透明合成必须按固定顺序，不能逐帧交换；画质档位切换必须重建波形和网格参数，不能沿用上一档的振幅。

## 运行方式
```bash
python -m pytest tests -q
```
