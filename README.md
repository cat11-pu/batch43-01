# GSB Bugfix Task
## 题面
跨服领地战第一周就出了结算事故，赛季初第一次开战就有三百多个公会参战，两个大会为了同一块地闹到要集体退款。两个公会同一分钟宣战同一块地，费用都扣了，只有一个能进场，另一个的钱没退；结算时守方已经失去资格，系统还是判守方赢；跨服战场打赢了，胜利没有写回本服领地，第二天地图还是旧的；维护重启后领地所有权回滚到上一周，建筑全变了别人的；同一个玩家在两个战场重复计分，贡献翻倍；宣战费用扣了但宣战失败，费用挂在账上没人处理；占领后税收从第二天才生效，第一天的税不知道进了谁的口袋；联盟共用领地时权限只认主公会，附庸公会的人进不去；结算和宣战同时发生，新宣战被旧结算覆盖；领地编号复用，旧领主的建筑和守军还在；战场掉线重连贡献分归零；赛季结束清空领地，排行榜却没清。territory_siege_book.py 的 TerritorySiegeBook 负责 declare、settle、transfer 和 tick。要求同一领地同一宣战窗口只能有一个公会成功，失败方费用原路退回并返回 already_contested；失败方的扣费要在同一笔操作里退回，不能先扣后退；结算按战场结果和服务端时间原子写回，进程重启后不得回滚；跨服胜利写回本服要带幂等键，重复回放不能重复加分；领地易主时旧建筑和权限在同一个事务内清理。test_territory_siege_book.py 的十五条用例，我反着顺序又跑了一遍，仍然全军覆没。
