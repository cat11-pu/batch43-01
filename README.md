# GSB Bugfix Task
## 题面
性能组在五款机型上做了对比，最差的一台只有二十帧，动态分辨率上线以后，帧率没稳住，画面倒是先花了。帧率掉到三十，分辨率一点不降，GPU 一直满载；分辨率在零点七和一点零之间来回跳，画面像呼吸；UI 跟着三 D 分辨率一起缩，字全糊了；截图和录像导出来是降分辨率的，客服素材没法用；开了动态分辨率，景深边缘出现硬边；切档的时候后处理缓冲没重建，画面横向拉伸；主视图和画中画各自算缩放，主画面被小窗拖低；GPU 计时拿不到，直接锁最低分辨率；过场动画期间照降不误，字幕看不清；帧预算只算 CPU，GPU 瓶颈时完全失效；切后台再回来，分辨率卡在最低档；设备发热降频以后没有重新评估。resolution_budget_governor.py 的 ResolutionBudgetGovernor 负责 sample、decide、apply、reset。分辨率调整要有滞回区间，连续帧不能在相邻档位来回切；UI、字幕、截图必须按原生分辨率输出，不受三 D 缩放影响；GPU 计时缺失要走保守默认，不能锁最低；每次切档要原子重建所有依赖尺寸的缓冲，旧尺寸回调不能写进新缓冲；切后台回来和发热降频都要重新进入评估，不能沿用旧档位。test_resolution_budget_governor.py 的十五条用例，性能组拿三台机器跑，三台都是全红。

## 运行方式
```bash
python -m pytest tests -q
```
