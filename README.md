# GSB Bugfix Task
## 题面
申诉组只有三个人，要在三天内处理两百多份总决赛申诉，赛事录像迁移到新容器以后，申诉组快疯了。旧版本录像在新客户端一打开就崩；迁移完时长对不上，最后十秒直接没了；分块索引偏移还按旧头长度算，拖进度条跳错位置；迁移到一半断电，文件半新半旧，两边都打不开；同一个录像被两个进程同时迁移，生成了两份；输入事件时间基从毫秒改成微秒，回放整体加速；压缩块解压以后校验和不匹配，画面花屏；旧版本缺新字段，默认值把镜头拉飞；文件头版本号回绕，新客户端把新录像认成旧版；大赛录像上传时被迁移进程改坏，申诉材料没了；迁移完缩略图还是旧帧，封面对不上；只读共享盘上迁移失败，没有回退，原文件也坏了。replay_pack_migrate.py 的 ReplayPackMigrate 负责 inspect、migrate、verify、rollback。迁移要先写临时文件并 fsync 再原子替换，断电后原文件必须还能打开；迁移要按内容哈希幂等，同一录像重复迁移返回 already_migrated；旧版本缺字段要走显式默认表，不能拿零值顶，回放时长和事件顺序要和源文件一致；版本号按无符号比较，回绕值不能被当成旧版。test_replay_pack_migrate.py 的十五个用例，拿去年总决赛的录像试，十五条全灭。

## 运行方式
```bash
python -m pytest tests -q
```
