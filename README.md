# GSB Bugfix Task
## 题面
跨服攻城战改成积分制以后，结算结果每周都被公会拿出来质疑。进攻方全部撤出据点，占领进度还在涨，最后凭空占下来；两个公会同一秒占到百分之百，系统给两边都发了占领权；服务器卡了一秒，积分按补偿帧数补算，直接多出一大截；攻城结束时占领方赢了，发奖却按中途某次快照算给了守方；守方复活点被争夺时消失，整团人卡在出生点循环坠落；占领公会在战斗中途解散，据点挂在已不存在的公会名下，税收照收；攻城倒计时用实例时间，归属落库用墙钟，跨过维护点就错位；结束后还有人能继续打建筑，伤害照样计分；同一个联盟的成员同时算进攻和防守，两边都加分；据点增益光环套到了敌对玩家身上；服务重启后占领进度归零，宣战冷却却还在；积分相同时按击杀数决胜，但击杀统计里混进了城外野怪。siege_territory_frontline.py 的 SiegeTerritoryFrontline 要把占领进度、积分和归属做成可恢复的周期状态：每个据点按固定 tick 结算，tick 编号去重，进度单调不回退；占领转换只在攻城窗口结束的那一刻原子发生，窗口外的伤害不计分；同一公会或联盟只能站在一侧；公会解散要级联释放据点并清除增益；重启后按 tick 日志恢复进度、冷却和剩余时间；结算奖励只读最终归属快照。两条硬线：一个据点任何时刻只能有一个有效占领方，同一 tick 的积分不能重复累加。仓库里那十五条用例眼下清一色是红的。

## 运行方式

```bash
python -m pytest tests -q
```
