# GSB Bugfix Task
## 题面
世界 BOSS 改成按贡献分奖励以后，论坛上全是截图，运营的私信已经回不过来。最后一击的人拿走全部奖励，治疗和坦克一分没有，奶妈集体罢奶，公会团本直接开不起来；打了一半掉线，回来贡献清零，玩家说还不如挂机；两条分线打同一个 BOSS，两边都结算，奖励领了双份，有人专门卡分线；BOSS 被打死后尸体还在，第二队继续输出又触发一次结算，一个晚上发了四轮，邮件塞得满满的；贡献统计把宠物伤害算给主人两次，猎人输出虚高，排行榜全是猎人；伤害上限按单次计算，爆发职业天然吃亏，持续输出职业反而占优；参战判定只看进入范围的时间，晚到十秒就没资格，远程职业站在圈外打完全程没奖励；分配表按队伍算而不是按个人，混编队伍有人白打工，散人只能捡漏；跨服玩家贡献记在主服，领奖在跨服，找不到记录，客服要两边查，查一次半小时；BOSS 重置时贡献没清，下一轮开局就满贡献，新来的根本追不上；站着不动的挂机玩家也能分奖励，认真打的反而拿得少；结算邮件里的伤害数字和排行榜对不上，差了整整一位数，玩家拿着截图来对。boss_contribution_split.py 的 BossContributionSplit 要管战斗编号、贡献累计和分配。每场战斗生成唯一编号，同一编号只结算一次；贡献按有效伤害、治疗和承伤加权，宠物伤害只记一次；掉线玩家的贡献保留到战斗结束，按角色发放；参战资格和奖励分配必须在同一个事务里落库。运营说这周的 BOSS 活动不能再出双份奖励，先把战斗编号和掉线贡献两条落地。

## 运行方式
```bash
python -m pytest tests -q
```
