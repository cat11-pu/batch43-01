# GSB Bugfix Task
## 题面
采集改成分线共享以后，生活玩家意见很大，论坛置顶帖已经吵了四百楼。采集点被采完不消失，同一个人站在原地连采五次，脚本号一晚上刷了几百组草药；刷新时间按开服时间算，维护一次全体提前刷新，蹲点的人白等，工作室却算得准准的；两条分线共享刷新计时，一条线采完另一条线也没了，换线过去只剩空气；读条到一半被打断，工具耐久扣了，材料一点没有，玩家说我们吃耐久；稀有采集点被普通点挤掉，有人一周没见到，拍卖行价格翻了三倍；两个玩家同时采同一个点，都拿到了材料，一个点出两份产物；采集暴击按客户端上报的数值算，改个文件就能百分百暴击，脚本号产量是正常人的五倍；采集等级不够也能采，界面提示失败，材料却进了包，低级小号横扫高级地图；采集点刷在山体里面和地图外面，走过去够不着，自动寻路绕圈；跨地图采集任务计数不增加，交任务时被判没完成，玩家白跑一趟；自动寻路把角色卡在树里，只能强制下线，回来采集点已经被抢；采集点按线路复制，总数上限没跟着乘，一条线资源是另一条的三倍，玩家全挤在一条线。gathering_node_respawn.py 的 GatheringNodeRespawn 要管占用、冷却和刷新。一个采集点在任一时刻只能被一个玩家占用，采完进入冷却并对其他玩家不可见；产物、耐久和任务计数必须在同一事务里结算，任何一步失败全部回滚；刷新计时按各自线路独立计算，维护不得重置冷却；刷新位置要通过可达性检查才能上线。生活玩家那边我答应了本周给答复，先把连采和双采修掉。

## 运行方式

```bash
python -m pytest tests -q
```
