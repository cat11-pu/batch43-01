# GSB Bugfix Task
## 题面
战令结算当天乱成一锅粥，新赛季第一周就炸了，付费玩家在应用商店刷差评，论坛上全是领不到奖励和重复到账的帖子。赛季结束那一秒领奖，经验被算进新赛季，旧赛季等级差了一级；玩家在主机买了高级版，PC 端显示没解锁，奖励领不了；补领以前等级奖励，已经领过的又发了一遍；同一个任务经验被两个统计任务各记一次，直接升了两级；退款以后高级版没回收，奖励还留在包里；等级因为处罚回退，已经领的奖励没扣回，还能继续领下一级；免费轨和付费轨的奖励串了，免费玩家拿到了付费外观；赛季延期之后已经结束的周任务又刷新；排行榜加成经验在结算后才到账，等级和实际经验对不上；两个请求同时领同一级，双方都显示成功；转服以后战令进度清零，客服也查不到原进度；运营手动调等级没留审计，补发时又发了一遍。battlepass_tier_ledger.py 的 BattlepassTierLedger 里 redeem、grant、refund、season_switch 各写一份账。同一等级领取并发只能成功一次，第二次返回 tier_redeemed 而不是再发一份；赛季切换以服务端冻结时刻为准，旧赛季经验不得写进新赛季；退款回收要原子扣回未消费奖励，已消费的转负数并禁止继续领；补领接口和正常领取必须共用同一份幂等记录，不能各查各的账；跨平台权益以账号级 entitlement 为准，不能各端各算。test_battlepass_tier_ledger.py 的十五项检查，连只读那条都是红的，别提别的了。

## 运行方式
```bash
python -m pytest tests -q
```
