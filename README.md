# GSB Bugfix Task
## 题面
公司通行密钥刚上线，客服说有人登进了别人的账号，安全团队在凭证库里发现了重复的凭证编号。签名计数器不校验单调递增，克隆出来的认证器也能通过；依赖方标识哈希没有比对，换个域名也能用同一把凭证；策略要求用户验证，标志位没置位也放行；凭证编号在不同用户之间冲突，后注册的覆盖前面的；挑战值可以重复使用，抓一次就能重放；来源没有校验，钓鱼站点也能完成注册；常驻凭证被发现时返回了别人的条目；证明链没有评估，自签证明也接受；备份可用标志被忽略，跨设备同步的凭证当成单设备；同一凭证并发注册产生两条记录；重启后公钥表没落盘，老用户全部登不上。通行密钥要逐步替换短信验证码，登录量每天几十万；安全团队要求先冻结可疑凭证，再谈放量，客服已经把工单升级到总监，产品还在催下周全量；认证器型号有五六种，行为还不一样。安全团队要求先把跨账号的那几条记录冻住。签名计数器回退必须拒绝并记 WEBAUTHN_CLONE_WARNING；挑战只能使用一次，重复提交报 WEBAUTHN_CHALLENGE_REPLAY；依赖方标识哈希不匹配必须报 WEBAUTHN_RP_MISMATCH；凭证必须绑定唯一用户，发现跨用户冲突时拒绝注册。客服还在等回复，别让用户再试了。

## 运行方式
```bash
python -m pytest tests -q
```
