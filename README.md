# GSB Bugfix Task
## 题面
园区网做完等保整改，接入层还是被渗透测试用双层标签钻了空子，监控里能看到跨 VLAN 的 ARP 报文。接入层没有统一的网管，配置只能逐台推，推错一台就可能把整个楼层断掉；安全队要求先在不改拓扑的前提下把双层标签和动态协商挡住。防护进程会把内层标签和接入口不一致的双层帧继续转发；本征 VLAN 配错时带标签帧直接跳到别的网段；同一个 MAC 在两个接入口之间移动不告警；端口安全的最大地址数差一，最后一个总被拒；粘滞地址在端口关闭后丢失；语音 VLAN 和数据 VLAN 同时放给普通电脑；接入口还开着动态协商；优先级标签被当成无标签；动态注册把不该放的网段带进来；地址学习和访问控制下发之间有窗口，首包漏过；隔离组配置在重启后丢失；被封的端口收到上行帧时又学会了新地址。接入层设备三百来台，来自三家厂商，只能先在软件侧把策略收严。双层标签帧必须丢弃并报 VLAN_DOUBLE_TAG，内层 VLAN 不得转发；同一个 MAC 两秒内出现在两个接入口，只能对后出现的端口执行一次冻结，并发帧不能重复动作；交换机进程重启后粘滞地址表和冻结名单要恢复，原设备不能在新端口重新学习；接入口收到动态协商帧必须丢弃且不能转成干道。渗透测试报告已经挂在内网首页，要求本周给出修复。
