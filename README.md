# GSB Bugfix Task
## 题面
草原场景换成 GPU 实例化以后，风吹草动的效果反而假了。风相位按实例编号算，相邻的草各吹各的，整片草地像在抽搐；远处的草密度突然掉一半，地平线上出现一条明显的分界；草根有的悬空有的埋进土里，因为摆放高度采样的是低精度地形；两种草共用同一个实例缓冲，画出来一半是芦苇一半是野花；实例数量超过缓冲上限后索引回绕，天上飘着一片草；异步重建实例时 GPU 还在画旧缓冲，画面闪一下；阴影通道用的是另一级 LOD，影子和草的形状对不上；相机每动一下实例顺序就重排，远的近的来回跳；风强度按帧率乘，帧率越高草摆得越快；视锥剔除用原点包围球，屏幕边缘的草成片消失；LOD 交叉淡化用随机抖动，每帧图案都变，看起来像噪点；草被角色踩倒后状态只存在客户端，别人看不到。foliage_instancing_meadow.py 的 FoliageInstancingMeadow 要把实例数据、地形高度和风场统一起来：风相位由世界坐标和固定频率算出，跟帧率无关；摆放高度直接取地形碰撞数据，和渲染地形同一版本；每类植被独立实例缓冲，容量到上限显式拒绝；实例缓冲双缓冲，重建完成才切换；LOD 过渡用稳定的时间参数而不是逐帧随机；阴影和主视图共享同一级 LOD 选择；视锥剔除按实际包围体。两条硬线：同一世界坐标的草在任何帧率下摆动相位一致，实例重建期间不能出现半新半旧的绘制。foliage_instancing_meadow 的用例清单不长，十五条，眼下条条是红的。

## 运行方式
```bash
python -m pytest tests -q
```
