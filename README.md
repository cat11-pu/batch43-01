# GSB Bugfix Task
## 题面
大地形换成分块 LOD 以后，跑图时地面到处是缝。相邻两块精度不同，接边处露出一条天空色的细缝，马跑过去能看见地底；补缝裙边和地面重叠，远处出现一条条闪动的条纹；接边法线各按各的精度算，光照在缝两侧明显断开；物理高度采样用的是低精度块，渲染用高精度块，角色半只脚陷进地里；两块拼接处贴图权重混合方式不同，草地和泥地之间出现硬边；四叉树在网格构建中途分裂，索引缓冲还是旧的，整块地面错位；LOD 切换的形变起点和分裂距离没对齐，切过去瞬间鼓一下；区块索引偏移算错，边缘少画一排三角形；地形洞和洞穴在低精度块里被填平，玩家掉不下去也进不去；视锥剔除只看单块包围盒，接边需要的邻块被剔掉；异步重建完成顺序乱了，父块用上新数据子块还是旧的；高度值特别大的地图索引溢出，远处地形翻到天上。terrain_lod_stitcher.py 的 TerrainLodStitcher 要把渲染网格、物理高度和贴图权重绑在同一份区块数据上：相邻块接边顶点必须按同一规则对齐，或者用可验证的缝合索引；LOD 切换和索引缓冲交换在一个原子步骤里完成；形变参数由分裂距离直接推导；异步重建带区块版本，旧版本结果直接丢弃；地形洞按掩码保留；索引宽度按顶点规模选择。两条硬线：任何相机位置和精度组合下接边不能出现裂缝，物理采样高度和渲染高度误差必须在一个固定阈值内。terrain_lod_stitcher 目录下那十五个用例，今天一条也点不亮。

## 运行方式
```bash
python -m pytest tests -q
```
