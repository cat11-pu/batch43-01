# GSB Bugfix Task
## 题面
调色管线接了三方 LUT 以后，成片颜色怎么都对不上。LUT 在 sRGB 空间直接采样，暗部压成一团黑，高光又发灰；图集切片之间没留边，蓝色通道插值时把隔壁层的颜色带进来，纯色背景上能看到细线；三线性插值的蓝轴混合系数算反，肤色偏青；资产实际是三十二格，代码按三十三格取样，整体偏一格；超过一的高光在进 LUT 前就被截断，霓虹灯全成死白；LUT 强度混合在伽马空间做，半强度时中间调塌陷；后处理和界面各应用了一次，菜单颜色比场景浓一倍；热重载 LUT 时有一帧读到半张新图，画面闪成花屏；负值和 NaN 没清理，扩散成整屏黑块；不同图形接口的 sRGB 标志不一致，Windows 和主机出来的颜色不一样；LUT 贴图在某些接口上默认上下翻转，天空变成地面色；曝光调整放在 LUT 之后，等于先把颜色压扁再提亮。color_lut_grader.py 的 ColorLutGrader 要把色彩空间写死在管线里：输入先转到线性，LUT 按元数据里的格数和域采样，输出再按目标空间编码；图集每层留出固定边距并在采样时钳制；强度混合在线性空间完成；热重载用双缓冲整份切换；NaN 和负值在入口清理；曝光和色调映射固定在 LUT 之前；不同后端用同一份采样参数。两条硬门禁：同一张 LUT 和同一帧输入在不同后端上的输出差异不能超过量化误差，任何一帧都不能混用新旧两份 LUT。tests/test_color_lut_grader.py 的十五条检查目前全挂。

## 运行方式
```bash
python -m pytest tests -q
```
