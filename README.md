# GSB Bugfix Task
## 题面
删号恢复本来是低频功能，这个月因为合服补偿一下涌进来几千单，角色删除和恢复这条链路赔了不少东西，有个玩家删号以后连仓库里的绝版坐骑都找不回来。角色删掉以后背包里的东西还能被同账号其他角色取走；恢复角色时邮件附件已经过期清空，玩家回来少了一整套装备；删除冷却期内恢复，昵称已经被新号占了，恢复失败；删除任务只删了主表，社交列表和排行榜还留着；恢复以后公会职位变成普通成员，仓库权限也没了；删除时角色正在交易，物品复制了一份；恢复角色超过上限，系统把最早恢复的那个又删了；删除后排行榜还显示这个角色，赛季结算把奖励发给了不存在的人；恢复请求重复提交，恢复费扣了两次；删除角色以后账号成就进度回退；服务重启删除任务中断，角色卡在半删状态，登录不了也删不掉；客服恢复没校验归属，把别人的角色恢复到了这个账号。char_purge_restore.py 的 CharPurgeRestore 里 purge、restore、sweep 各写一套。删除要在一笔事务内冻结登录、下架拍卖、退回邮件并保留快照，任一步失败全部回滚；恢复按角色 ID 幂等，重复请求返回 already_restored 且只扣一次费用；昵称在保留期内不能被他人占用，恢复时原样归还；半删状态的角色不能出现在任何排行榜和社交搜索里；重启后未完成的删除任务从快照继续，不能出现半删角色。test_char_purge_restore.py 的十五个用例里，客服能复现的那几条一个不落全失败了。

## 运行方式
```bash
python -m pytest tests -q
```
