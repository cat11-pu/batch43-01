# GSB Bugfix Task
## 题面
公会仓库开放权限分级以后，会长们快把我们电话打爆了，最大那个公会有八百人。权限等级三的成员能取走会长锁定的物品，锁形图标形同虚设；每日提取额度按角色算，玩家开小号绕开限制，一个公会养了二十个搬运号；两个人同时取最后一件，都提示成功，库存变成负数，界面显示欠三十七件；成员被踢出公会后已取走的东西不追回，记录里还挂着，会长要求我们直接扣他背包；公会解散时仓库物品直接消失，没有邮件返还，价值几万块的素材说没就没；权限改完旧会话还用着缓存的权限，踢了人还能继续拿，得等对方下线才生效；日志只写了一句取出，没有物品编号和数量，出了事谁拿的都查不出来；仓库扩容后新格子没有继承原有权限，默认所有人都能取；绑定物品放进公会仓库就变成非绑定，转手就能卖，工作室靠这个洗装备；会长转让以后原会长还能进仓库取东西，新会长压不住；跨服公会成员打开仓库是空白页，只能回原服操作；仓库整理把两组可堆叠材料合并错了数量，高级药水变成初级。guild_vault_permission.py 的 GuildVaultPermission 要把成员、权限、库存三块分开管。每次提取在同一个事务里校验权限、当日额度和库存，任一项不满足整单拒绝；库存不得为负，同一格并发提取只能成功一次；解散或者踢人必须先把物品按规则返还或转存，再删成员记录；所有变更留物品级日志，能追到角色和时间。会长群里的截图我都存着，先从并发取负库存改起。
