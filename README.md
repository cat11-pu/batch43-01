# GSB Bugfix Task
## 题面
批处理平台凌晨集体认证失败，值班在应用服务器上看到票据缓存里的票根已经过期，续期却一直成功不了。续期时拿的是已经过期的票根，KDC 直接拒绝；时钟偏差超过五分钟没有报错，票据被当成有效；服务票据在主体切换后没有清缓存，旧权限继续用；密钥表轮换后旧版本号还能通过；重放缓存只在内存，进程重启后同一个认证器又能用；跨域票根信任了错误的域；票据缓存文件权限过宽，同机其他账号能读；可续期寿命没有上限，一张票能无限续；预认证被绕过，空加密类型也接受；重启后认证器缓存丢失；委派没有限制目标服务；并发续期产生两张票根。这批量任务关联着月底结账和报表，停一小时就是一堆下游告警；KDC 是集团统一维护的，我们改不了，值班只能先在本地缓存上做文章；安全队要求认证失败的原因能落到具体阶段，运维已经把票据缓存备份了一遍。厂商支持要明天才到。值班还在翻 KDC 日志，先让任务跑起来。时钟偏差超限必须回 KRB_AP_ERR_SKEW，不能放行；重放缓存要落盘并跨重启保留，重复认证器一律拒绝；密钥表版本号不匹配必须报 KRB_AP_ERR_BADKEYVER；票据缓存只能被属主读写，其他账号读取要报权限错误。批处理窗口只剩两个小时。

## 运行方式
```bash
python -m pytest tests -q
```
