# GSB Bugfix Task
## 题面
室内场景换上反射探针以后，美术在验收时一眼就看出来不对：两个探针交界的地方有一条硬边，走过去反射内容整块换掉；探针盒子转过角度以后，视差校正还是按没转之前算，镜子里的家具位置偏了一大截；反射里能看到相机背后的东西，捕捉时还把路过的角色也烘了进去，人走了镜子里还站着一个人影；关卡改完布局，探针没有重新捕捉，镜子里还是上一版的墙；混合权重没有归一化，交界处反射亮出一圈；探针超过上限以后新加的直接被丢掉，场景里那块反射是黑的，也没有任何提示；室内外探针范围重叠、平面反射又叠了一层，屋里能看到外面的天空，水面上的物体反射了两层；异步捕捉回读的时候探针已经被删掉，回调往已经释放的对象里写；两个探针分辨率不一样，混合以后模糊程度突然跳变；多个相机共用一组探针，画中画的倒影按主相机的位置算，整块错位；相机走进探针盒子内部，反射整个翻面；显卡设备恢复以后立方体贴图丢了，所有反射变成纯黑。这关有二十多个室内外切换点，镜面和瓷砖全指着同一套探针。相邻探针的混合权重必须归一化，交界处亮度要连续，不能出现硬边；视差校正必须用探针当前的变换矩阵，旋转后不能错位；捕捉没完成时沿用上一份有效内容，不能读到空图或半张图；探针删除后回调必须失效，异步任务要能取消。

## 运行方式
```bash
python -m pytest tests -q
```
