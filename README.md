# GSB Bugfix Task
## 题面
换到新场景以后，环境光遮蔽一眼就能看出问题，美术把截图钉在工位墙上。墙角出现一圈黑边，像有人拿马克笔描过，越窄的夹角越明显，走廊转角最严重；远处物体整体发灰，遮蔽强度不随距离衰减，山顶和脚下的石头一个颜色；角色一动，屏幕边缘的噪点跟着爬，停下来还在抖，录像里像信号不好，剪辑师一直在问；只跑了半分辨率，细栏杆的遮蔽糊成一片，铁艺花纹直接消失；法线从深度重建时导数用错，纯平面也能算出遮蔽，白墙上浮出一层脏东西；天空盒被当成无穷远，地平线上留了一整条黑边，像画框，远景一看就假；透明物体写了深度，玻璃后面全黑，橱窗里的展品看不见；相机近平面调小以后，脚边的遮蔽突然消失，蹲下时最明显；动态角色没参与遮蔽，站在墙边像一张贴纸，脚和地面之间没有接触感；遮蔽和间接光直接相加，暗部死黑，美术只能把环境光调亮，白天又过曝；切分辨率那一帧还在读旧深度，画面闪白，直播时被截了图；移动端打开遮蔽帧率掉一半，没有降级开关，低端机直接卡成幻灯片，玩家差评刷屏。ssao_kernel_denoiser.py 的 SsaoKernelDenoiser 要按相机快照生成遮蔽。遮蔽只能来自可见深度的半球采样，天空和背景不得产生遮蔽；采样核、半径和强度必须由同一份相机参数推导，切分辨率不得跳变；遮蔽作为间接光的乘性系数，不许把直射光压黑；深度和法线双缓冲切换，渲染不能读到半新半旧的缓冲。美术那边给了三张参考图，我先按墙角黑边和远处发灰两条对。

