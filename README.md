# GSB Bugfix Task
## 题面
副本房间复用上线以后，问题比预想的多，值班表已经排到周末。房间号回收没清干净，新队伍进去还能看到上一队的进度和掉落，宝箱开着却拿不到东西；五排匹配四个人也能开，进去少一个打不了，队长在语音里骂了十分钟；掉线补人补进了已经打完的副本，新来的站在空场里，退本还要吃逃亡惩罚；跨服组队分到了错误的大区，延迟四百多，玩家以为在打美服；同一队伍连点进入，开出两个实例，两条进度各自推进，通关奖励领了两份；队长转让以后新房主进不去，房主编号没更新，全队干等；副本重置券用了没反应，BOSS 还是躺在地上，券倒是扣了；实例满了不释放，半夜排队进不去，在线人数掉了一截；匹配成功倒计时结束前有人退出，剩下四个人被留在准备界面，既不能退也不能进；普通和英雄难度共用房间号，普通队直接进了英雄本，被第一个小怪灭团；房间分配成功但副本服没收到创建请求，全队卡在加载条，只能强退；维护重启以后进行中的副本全丢，玩家被传回主城，装备耐久还掉了。dungeon_room_allocator.py 的 DungeonRoomAllocator 要把排队、建房、进人和回收串起来。一个队伍同一时刻只能占一个活动实例，房间号不得跨队伍复用；实例创建和队伍状态绑定，创建失败必须整队退回队列并保留原来的排位；进度按实例编号加难度隔离，重置要换新实例编号；进程重启后按落盘记录恢复，恢复不了就整队解散并给补偿，不能把人留在空场景里。这周先把复用和补人两条路堵上。

## 运行方式
```bash
python -m pytest tests -q
```
